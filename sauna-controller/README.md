# Sauna Controller

> **Status**: 🔗 External repo — this project lives in its own dedicated repo.

A custom ESP32-based controller for an electric sauna, with thermostat,
RGBW lighting, RS-485 panel transport, and safety interlocks (door-open
timeout, software high-temp limit, welded-contactor detection).

Too large to live as a subfolder here. See:

➜ **<https://github.com/alexlmiller/sauna-controller>**

## Why it's separate

This project is a full appliance build with its own hardware design,
panel firmware, schematics, and operating manual. Keeping it as a
standalone repo keeps issue tracking, releases, and contributors scoped
to that one device.

This stub exists so the device gallery on the homepage stays complete.
